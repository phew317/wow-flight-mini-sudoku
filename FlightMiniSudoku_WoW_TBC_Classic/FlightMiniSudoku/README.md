# Flight Mini Sudoku – WoW Burning Crusade Classic

Version: 2.9
Interface target: 20506

A compact 6x6 Sudoku addon for World of Warcraft.

## Features
- 6x6 Sudoku board with 2x3 blocks
- Timer, hints, hint penalties and personal best tracking
- Top 20 leaderboard with WoW class colors
- Private addon-message synchronization with online friends and guild members
- Optional automatic opening when a taxi flight starts
- Minimap launcher and German/English localization

## Installation
Extract the `FlightMiniSudoku` folder into the game's `Interface/AddOns` directory.

## Notes
This archive is built for the client version stated above. Other WoW client versions may require a separate build.
The multiplayer highscore synchronization requires other players to have a compatible version of the addon installed.
